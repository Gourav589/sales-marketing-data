# Sales & Marketing Data Analysis 📊

A Python-based data analysis project that explores sales trends, regional profitability, and category performance from a retail dataset — combined with a simple machine learning model to forecast future sales.

## 🎯 Project Overview

This project analyzes the **Superstore Sales Dataset**, uncovering business insights around:
- Which product category drives the most revenue
- Which region generates the highest profit
- How sales trend over time (month by month)
- A basic linear regression model to predict sales for the next 3 months

## 🛠️ Tools & Libraries

- **Python**
- **Pandas** — data cleaning and aggregation
- **Matplotlib / Seaborn** — data visualization
- **scikit-learn** — Linear Regression model for sales forecasting

## 📈 Key Insights

- Technology category generated the highest total sales among all categories.
- Sales revenue shows a clear upward trend over the analyzed period.
- A linear regression model was used to forecast the next 3 months of sales based on historical monthly trends.
